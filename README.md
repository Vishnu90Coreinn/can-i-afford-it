# Can I Afford It?

Privacy-first purchase impact simulator. Built with Next.js + TypeScript for Vercel. All financial calculations run in the browser; no database or account is required.

## Core principles

- Separate available savings from emergency savings
- Measure purchase impact instead of issuing fake financial verdicts
- Compare cash vs EMI using true financing cost
- Show liquid runway before/after purchase
- Support wait, stress, reserve-target and ownership-cost scenarios
- Keep user-entered financial values client-side

See `CALCULATION-SPEC-v1.md` for the frozen calculation rules.
